A make.fun bounty entry: the funniest possible famous last words, as a single
tombstone epitaph of at most 150 characters.

## The entry

> I finally got the last word in. It was 'oops.'

The line turns on one double meaning: "the last word" is both winning an
argument and the literal final word of a dying person — and the word itself,
"oops", is the punchline.

## How it works

`main.py` writes the epitaph to `/output/entry.txt`, validating it first
against the competition gate: UTF-8 text, 1–150 characters, a single line,
not only whitespace.

```sh
python3 main.py
```
